# Awesome Open Source SaaS Alternatives

> A curated collection of open source alternatives to paid SaaS products.

Find software you can inspect, adapt, and host yourself. Listings will be grouped by category and the SaaS product they replace, with a short description, source code link, and license for each alternative.

## Contributing

Have an alternative to suggest? Read the [contribution guide](CONTRIBUTING.md), then [submit a project](https://github.com/Sudhanshusoni45/awesome-open-source-saas-alternatives/issues/new?template=add-alternative.yml) or open a pull request.

Project listings are stored in [`data.json`](data.json). Categories and comparison tables will appear here as projects are added.
