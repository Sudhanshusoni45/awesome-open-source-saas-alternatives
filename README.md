# Awesome Open Source SaaS Alternatives

> A curated collection of open source alternatives to paid SaaS products.

Find software you can inspect, adapt, and host yourself. Listings are grouped by category and the SaaS product they replace, with a short description, source code link, and license for each alternative.

## Alternatives

### Analytics

#### DataFast

Web analytics focused on traffic sources, conversions, and revenue attribution.

| Alternative | Description | License |
| --- | --- | --- |
| [Minilytics](https://github.com/surendrapandar/minilytics) | Self-hosted web analytics on Cloudflare that connects traffic sources to conversions and revenue. | MIT |
